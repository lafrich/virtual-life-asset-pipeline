Layar: Skala:
Klik tombol HP di gambar, atau keyboard: ↑↓ gulir · Enter/Space = tombol tengah (OK) · ←/F1 = softkey kiri (Pilih) · →/Backspace/F2 = softkey kanan (Kembali/Hapus) · 1–9 0 * # keypad · C = Call (hijau) · Esc/E = End (merah: ke Standby, di Standby = tutup HP). Saat HP tertutup: klik tombol HP kanan atas atau tekan Enter/H. Semua nama, angka, teman, item = data contoh kecuali Rp 1.250.000 dan Basic Trading Course (Rp 300 / 90 detik / +40 Trading XP) dari brief.
