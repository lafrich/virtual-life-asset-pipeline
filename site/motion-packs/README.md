# Mahluk Hidup — native V6B animation registry

There are no bundled non-native motion assets. The 11 original V6B actions
(walk, idle, talk, sit, sit_type, sleep, tired, swim, float, lie, perch)
continue to use their unchanged 384×4928 layered atlases. Emosi and Custom
Wear are separate and must not be edited when removing bad animations.

Rejected JSON cutout motions (including Standing Punch) are not stock.
Future animations must follow the native pixel-layer authoring and four-view
validation process rather than importing unreviewed experimental clips.
